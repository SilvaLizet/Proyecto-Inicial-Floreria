**Prompt para la IA**
Actúa como un Arquitecto Senior de Software con especialización en el ecosistema Flutter y experto en infraestructuras Cloud con Firebase. Tu misión es liderar la planificación técnica y estratégica de una aplicación multiplataforma de gestión integral para una florería y centro de jardinería profesional. La solución debe estar diseñada para ejecutarse con un rendimiento óptimo en Android, Web y Windows, utilizando VS Code como entorno de desarrollo y Firebase en una configuración estándar de desarrollo.

Bajo ninguna circunstancia debes generar código todavía. El entregable debe ser un documento de planificación maestro en formato Markdown, redactado con un tono humano, técnico y pedagógico, que fusione la estética visual del diseño floral con una ingeniería de datos robusta basada en las siguientes entidades: Proyectos de Paisajismo, Categorías de Plantas, Cuentas de Inventario/Caja, Usuarios (Roles), Transacciones (Ventas/Compras), Presupuestos de Servicios, Proveedores de Insumos y Facturación.

El documento debe estructurarse de la siguiente manera:

En primer lugar, desarrolla una descripción general del sistema que explique cómo esta plataforma digital transformará la operación diaria de la florería, integrando la gestión de stock con la administración de servicios de jardinería. Posteriormente, define una arquitectura de software escalable para Flutter; dado que no se debe usar el paquete provider, propón una estructura basada en el patrón de Inyección de Dependencias y Servicios (o alternativas como Riverpod o BLoC si se considera necesario para la escala del proyecto), detallando la organización de carpetas por capas y la separación estricta entre la lógica de negocio y la interfaz de usuario.

En la sección de tecnologías, justifica el uso de Dart y Firebase, profundizando en cómo Firestore gestionará los documentos de productos y ventas, cómo Firebase Authentication manejará el acceso del personal y cómo Firebase Storage almacenará las fotografías del catálogo botánico. Describe un diseño UI/UX que evoque la naturaleza: un estilo moderno, responsive y profesional, con una paleta de colores orgánica y una navegación intuitiva que se adapte perfectamente tanto a una tablet en el mostrador como a una aplicación de escritorio o navegador web.

Para la planeación del desarrollo, establece una hoja de ruta dividida en diez fases detalladas: desde la configuración inicial y el diseño de la base de datos NoSQL en Firestore, hasta el desarrollo de los módulos CRUD, la lógica de transacciones en tiempo real, la gestión de facturación y las pruebas de despliegue multiplataforma. Cada fase debe incluir objetivos claros, herramientas específicas, buenas prácticas de codificación y una sección de gestión de riesgos con soluciones recomendadas para problemas comunes en Flutter.

Adicionalmente, incluye una sección de dependencias críticas para el archivo pubspec.yaml, explicando la utilidad técnica de cada una en el contexto de la jardinería (manejo de imágenes, fechas, gráficas de ventas, etc.). Finaliza con una estrategia de seguridad basada en reglas de Firestore y roles de usuario, un diagrama narrativo del flujo de navegación y un plan de implantación profesional para el despliegue de versiones de prueba en Android y Web. El documento debe concluir con una serie de recomendaciones de "Senior Developer" sobre optimización de consultas en Firestore, rendimiento de la UI y mantenimiento de una arquitectura limpia para asegurar que el proyecto sea un éxito rotundo.
